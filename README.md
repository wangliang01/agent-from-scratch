# agent-from-scratch

> 先手写，再上框架。

## 为什么叫这个名字

招聘里写的「AI Agent 开发」，绝大多数其实是 **LLM 应用工程**：把大模型接进真实系统，让它能查工具、读资料、按流程干活，并且出错时能兜住。

这门手艺的核心不是记住某个框架，而是先搞懂那个 `while` 循环到底在转什么。所以这个仓库不教你背名词，名字本身就是结论：**从零手写一遍，再谈框架**。

## 一、招聘要求拆开看，其实是四块能力

| 能力 | 具体要会什么 |
| --- | --- |
| 调 LLM API | 流式输出、结构化输出、错误处理、token 计费 |
| 工具调用（tool calling） | 定义工具、执行工具、把结果塞回对话 |
| RAG | 切块、embedding、检索、rerank、效果评测 |
| 编排 | 多步循环、状态管理、失败重试、人工确认 |

再加一个把它们串起来的东西：**评测**。没有评测集，所有优化都是瞎调。

好消息：不需要训练模型，不需要啃 Transformer，不需要数学。你要做的是「接线工 + 质检员」。

## 二、学习顺序：反着来

普通教程：原理 → 数学 → 框架 → 应用。
这里：**先跑通 → 卡住了再补原理**。

- 第 0 天：Python + `uv` + 官方 SDK，**不装任何 Agent 框架**
- 第 1 周：手写最小 Agent（50~100 行）
- 第 2 周：RAG
- 第 3 周：编排 + MCP
- 第 4 周：上线能力

详细内容见 [`docs/methodology.md`](docs/methodology.md)。

## 三、四周路线一览

| 周次 | 主题 | 这一周做完你能拿出什么 |
| --- | --- | --- |
| 第 1 周 | 手写 Agent 循环 | 一个 50~100 行、能自己调工具的小 agent |
| 第 2 周 | RAG | 一个能回答私有文档问题、并且有召回率数字的问答 |
| 第 3 周 | 编排 + MCP | 一个多步任务 agent（带失败重试、断点续跑）+ 一个自己写的 MCP server |
| 第 4 周 | 上线能力 | FastAPI 接口 + SSE 流式 + 日志 + eval 回归，有可访问的 URL |

## 四、三个作品（作品集）

1. **垂直领域 RAG 应用** —— 真实数据 + 强制引用 + 评测数字（例如「召回率 62% → 85%」）
2. **多工具 Agent** —— 多步任务 + 工具失败重试 + token 统计
3. **一个小而完整的 MCP server** —— 小没关系，完整（有工具、有错误返回、有说明）比花哨重要

不要做「通用聊天机器人」。那不是作品，那是demo 的起点。

## 五、面试高频 6 问

1. 怎么防止 RAG 幻觉？—— 检索约束 + 强制引用 + 检索不到就拒答
2. 长对话上下文怎么管理？—— 摘要压缩 / 滑动窗口 / 外部记忆
3. 工具调用失败怎么办？—— 参数校验 + 重试 + 把错误当结果让模型自己改
4. 怎么评测 Agent？—— 先建 30~50 条 eval set，再谈优化
5. 成本怎么降？—— prompt 缓存 / 小模型分流 / prompt 压缩
6. 为什么不用 LangChain？—— 说出具体抽象泄漏点，而不是「它太重了」

每题的答案骨架在 [`docs/methodology.md`](docs/methodology.md#五面试高频-6-问)。

## 六、避坑清单

1. 别一上来学 LangChain —— 先手写循环，否则框架帮你做的每一步你都不知道
2. 别做通用聊天机器人当作品 —— 要垂直、要有数据、要有数字
3. 别只看教程 —— 代码跑起来、卡住、查文档、修好，这才叫学会
4. 别背名词 —— ReAct、CoT 谁都会说，面试官要听的是你踩过什么坑
5. 别跳过评测 —— 没有 eval set 的优化，等于闭着眼睛调遥控器

## 七、时间账

**每天 3 小时 × 28 天 ≈ 84 小时。**

这不是「碎片时间随便看看」能完成的量，但也不需要脱产。按周验收，每周都要有一个能跑的东西。

## 八、怎么开始

```bash
cd /d/wangliang/ai/agent-from-scratch

# 1. 装依赖（本项目用 uv 管理，Python 3.12）
uv sync

# 2. 配置 API key
cp .env.example .env
#   编辑 .env，填入真实的 ANTHROPIC_API_KEY

# 3. 跑第 1 周的最小 Agent
uv run python week1-mini-agent/agent.py "帮我算 (123 * 456) + 78，再告诉我北京的天气"
```

第一步的讲解见 [`week1-mini-agent/README.md`](week1-mini-agent/README.md)。
