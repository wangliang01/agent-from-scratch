# MCP Server 骨架

> 一个"小而完整"的 MCP server 比一个半成品大项目更值钱。

## 要做什么

选一个你熟悉的领域（例如：查询你自己的笔记库），暴露 2~3 个工具：

- `search_notes(query)`：搜索笔记
- `read_note(id)`：读取某条笔记
- `list_topics()`：列出所有主题

## 完整性的标准

- [ ] 每个工具有清晰的输入 schema 和描述
- [ ] 错误有明确返回（不要吞异常）
- [ ] 有 README 说明安装和接入方式
- [ ] 有一个能手动验证的调用样例

## 提示

先想清楚"谁会用它、用来干什么"，再写代码。

详细方法论见 `../../docs/methodology.md` 第四节。
