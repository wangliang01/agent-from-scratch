# 第 3 周：编排 + MCP

> 目标：把单次工具调用升级成能跑多步任务、失败能兜住的 agent。

## 编排要手写一遍的东西

- **状态机 / 图**：LangGraph 或自己写 `State` 类，关键是理解状态如何流转。
- **失败重试**：指数退避 + 最大次数。
- **human-in-the-loop**：敏感操作（删文件、发请求）前停下来让人确认。
- **断点续跑**：状态序列化到文件/DB，崩了能接着跑。
